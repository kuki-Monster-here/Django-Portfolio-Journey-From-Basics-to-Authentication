## 📚 Проекты

### 1. [📖 Основы Django: Личная библиотека](./01_django_basics_library)
**Ключевые навыки:** Структура проекта Django, модели (Models), миграции, встроенная админ-панель.

> **💡 Ассоциация:** Научилась создавать "чертежи" данных (модели) и получила "пульт управления" для них (админку) без написания фронтенда.

**Что внутри:**
- Модель Book с полями: название, автор, год издания
- Автоматически сгенерированная админ-панель
- Миграции базы данных

### 2. [🎨 Шаблоны и Формы: Библиотека+](./02_templates_forms_library_plus)
**Ключевые навыки:** Архитектура MVT (Model-View-Template), HTML-шаблоны, Django Forms, обработка пользовательского ввода.

> **💡 Ассоциация:** "Оживила" данные, создав для них пользовательский интерфейс. Фронтенд и бэкенд научились общаться через формы.

**Что внутри:**
- Полноценные HTML-шаблоны с наследованием
- Формы для добавления и редактирования книг
- Валидация пользовательского ввода

### 3. [👥 Пользователи и Права: Менеджер задач](./03_auth_task_manager)
**Ключевые навыки:** Система аутентификации Django, авторизация, связи между моделями (ForeignKey), личные кабинеты.

> **💡 Ассоциация:** Создала безопасное многопользовательское приложение с разграничением данных. Понимаю разницу между "кто ты?" (аутентификация) и "что тебе можно?" (авторизация).

**Что внутри:**
- Регистрация и вход пользователей
- Личный кабинет с задачами (To-Do)
- Каждый пользователь видит только свои задачи
- Защита маршрутов декоратором @login_required

## 🚀 Технологический стек

- **Backend:** Django 4.2, Python 3.11+
- **Database:** SQLite (для демонстрации)
- **Frontend:** HTML, CSS, Bootstrap (в проектах 2 и 3)
- **Система контроля версий:** Git

## 🛠 Как запустить проекты

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/kuki-Monster-here/django-portfolio-journey.git
cd django-portfolio-journey

# 2. Выберите проект  
cd 01_django_basics_library  # или другой проект

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Запустите сервер
python manage.py migrate
python manage.py runserver

# 5. Откройте в браузере
# http://127.0.0.1:8000
